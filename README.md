# Plotting scripts and animations for Jain & Sobolev (2026a, JGR: Solid Earth)
Plotting scripts and animations for Jain, C., &amp; Sobolev, S. V. (2026), Controls on the tectonic evolution of the early Earth: 1. Composite rheology. *Journal of Geophysical Research: Solid Earth*, 131, e2026JB034559. [https://doi.org/10.1029/2026JB034559](https://doi.org/10.1029/2026JB034559)

# Repository structure
    .
    ├── /data                           # Simulation data files, to be downloaded
    ├── /figures                        # Figures
    ├── /scripts                        # Plotting scripts
    ├── /animations                     # Animations for reference models
    ├── LICENSE                         # License agreement
    └── README.md                       # This README file

# Simulation data

In order to execute the plotting scripts, please download *data_and_scripts.zip* from [https://doi.org/10.5281/zenodo.22734764](https://doi.org/10.5281/zenodo.22734764) and unzip it in */data/*. Plotting scripts only work when this simulation data set is present in the data folder.

# Software requirements

Python 3.x, see the individual plotting scripts for the required packages.
